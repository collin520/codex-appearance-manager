# Preview editing prompts

Mode: built-in image generation, one edit per owner-provided screenshot. No CLI/API-key fallback was used. Input roles: each screenshot was an edit target, not a style reference for a newly designed interface. Original screenshot paths and private content are intentionally omitted from the public record.

Preserve the exact application layout, original background illustration, scene characters, theme styling, transparency, borders, native icons, toolbar, sidebar width, composer, typography size and screenshot framing. Do not redesign or beautify the CSS. Do not flatten the glass surfaces or make them opaque.
Replace the active tab and selected conversation title with "Theme Showcase". Keep standard product/UI labels such as Codex, Your dot, 新聊天, 置顶, 项目, 最近, 展开显示 and the model controls unchanged. Replace ALL other sidebar names/titles with fictional generic English labels, in the same rows, matching font size and color: "Demo Workspace", "Design brief", "First steps", "Theme preview", "Component gallery", "Notes", "Sample App", "Build a simple interface", "Theme Lab", "Demo Website", "Review the layout", "Refine colors", "Playground", "Preview components", "Check contrast", "Try a new background", "Widgets". No old personal/business project name or chat topic should remain anywhere, including faint text in clipped areas.
Replace the top clipped user message with "Can you help me create a calm, readable workspace?" Replace every assistant paragraph using short readable fictional demo text, preserving its original theme color (do not turn forest text pink, and do not turn rainy pink text green):
"Here is a simple demo workspace with a custom background and readable glass panels."
"The sidebar, composer and small cards follow the same visual style."
"This example shows theme styling only. Some interface states may still need adjustments."
"We can review contrast, spacing and the background crop in both narrow and wide windows."
"Keep the interface familiar and make the workspace feel personal."
Replace every activity pill label with generic demo labels such as "Reading demo files", "Editing theme styles", "Running local checks", "Previewing components", "Demo review started", "Demo review complete". Replace the elapsed status with "Demo session". Replace the file-change pill with "3 files changed +24 -8". Remove any residual actual counts, timelines, skills names, paths, business details or chat quotes. Preserve pill outlines and fills. Replace the bottom-left personal avatar with a generic abstract circle avatar in the theme palette, with no real face. The composer placeholder may say "Type a message".
Add a small understated label "Privacy-edited demo" in the top-right title-bar empty area, matching the theme text color, without obscuring toolbar controls. This distinguishes the illustration as edited. No added app capabilities, advertising frame, decorative text outside the window, blur blocks or censorship bars. Aim for crisp, natural screenshot typography and preserve the entire window. All original private text must be fully removed, not merely covered by translucent paint.
Theme invariant: this edit target uses Enchanted Forest. Keep the green/mint/gold glass UI and the lush woodland artwork with fairies and cute animals absolutely unchanged. Do not alter the animals or fairies.
